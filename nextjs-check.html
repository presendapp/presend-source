Is this site's Next.js up to date?

Enter a website address. We read the Next.js version from the JavaScript files its homepage loads, and list the published security advisories for that version, with the version to move to.

Free, no sign-up. Only public files are read, like a browser or Wappalyzer would; nothing is tested or sent to the site. Results are cached for an hour.

Why it matters

In November 2026 we found that 2 in 3 agency-built Next.js sites ship a version with a critical advisory. Next.js has published several critical advisories in 2026, including unauthenticated remote code execution in the image optimisation API. Some are fixed only in 15.5 and 16.x: sites still on 13.x or 14.x have no patch release left and need a major upgrade. Many sites keep running the version they launched with, because nobody is paid to update them after delivery.

How it works

  • The page fetches the homepage and up to 20 of the /_next/static/ scripts it references, and reads the version Next.js embeds in them.
  • Advisories come from the public OSV database, which mirrors the GitHub Security Advisories for the next package.
  • It only covers Next.js itself, not the site's other dependencies, its server configuration or its code.

Some sites hide the version (custom builds, scripts served from another domain): the check then says it could not read it.
