# Code of Conduct

## Our Standard

Presend is a small, free, open-source project. Contributors and users are expected to:

- Be respectful and constructive in issues, discussions, and pull requests
- Focus criticism on code and ideas, not people
- Accept that maintainer time is limited and volunteer-based

Harassment, personal attacks, and spam are not tolerated.

## Scope

This applies to all Presend repositories (issues, PRs, discussions) and any official Presend community spaces.

## Enforcement

Violations may result in comments being removed, issues/PRs being closed, or contributors being blocked, at the maintainer's discretion. There is no formal appeals process for a project this size -- if you believe a decision was made in error, open a new issue explaining why.

## Reporting

For conduct concerns, open an issue or use GitHub's [report abuse](https://github.com/contact/report-abuse) feature for serious violations. For security vulnerabilities specifically, see [SECURITY.md](SECURITY.md) instead.

This is adapted informally from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), scaled down for a small project.
