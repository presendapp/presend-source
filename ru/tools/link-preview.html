Как это работает?

Когда вы вводите URL, наш серверный прокси получает содержимое страницы от вашего имени — обходя ограничения CORS браузера. Затем он анализирует HTML для извлечения тегов Open Graph (og:title, og:description, og:image, og:site_name) и переключается на стандартные HTML-теги при отсутствии данных OG. Извлечённые метаданные возвращаются в виде структурированного JSON и отображаются в виде визуальной карточки предпросмотра. Presend не сохраняет URL (ваш IP может храниться до 2 минут как ключ ограничения частоты запросов). Проверяемый сайт видит запрос от сервера Presend, а затем ваш браузер загружает изображение предпросмотра и favicon напрямую с этого сайта, который поэтому тоже видит ваш IP.
