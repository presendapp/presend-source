Frequently asked questions

What is SHA-256?

A cryptographic hash producing a unique 64-char fingerprint.

Why verify integrity?

To confirm a file was not corrupted or tampered with.

Which algorithms?

SHA-256, SHA-1, SHA-512.

File uploaded?

No. Processed locally via Web Crypto API.

Large files?

No practical limit, processed in chunks locally.
