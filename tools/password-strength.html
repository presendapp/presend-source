    Frequently asked questions

    How is password strength calculated?

    The tool analyzes length, character variety (uppercase, lowercase, numbers, symbols), and estimates entropy — the measure of unpredictability in bits.

    What is a good password entropy?

    A password with 60+ bits of entropy is considered strong. 80+ bits is very strong. Below 40 bits is weak and should be avoided. These figures assume a randomly chosen password: dictionary words, names and keyboard patterns are far weaker, and a passphrase is estimated per word (about 13 bits per randomly chosen word).

    What is "estimated crack time"?

    It is a rough estimate of how long it would take a modern computer to brute-force your password. It assumes the attacker knows the character sets used.

    Does the tool store my password?

    No. The analysis happens entirely in your browser. Your password is never sent to any server or stored anywhere.
