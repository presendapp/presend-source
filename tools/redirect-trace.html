Frequently asked questions

  

    

      Why check the whole redirect chain instead of just the final URL?
      
A link can look safe at a glance and still route through several intermediate domains before landing somewhere unexpected -- a common cloaking technique. Seeing every hop, not just the destination, is what catches this.

    

    

      What counts as a cross-domain jump?
      
Any hop where the redirect target's domain differs from the previous hop's domain. A chain that stays on one domain the whole way is generally less suspicious than one that bounces across several unrelated domains.

    

    

      How many hops does this follow?
      
Up to 15. If a chain exceeds that, it's flagged as suspiciously long rather than followed indefinitely.

    

    

      Can I use this in my own code?
      
Yes. This page calls the same free, public API endpoint you can call directly: GET /api/redirect-trace?url=https://example.com. No signup or API key required.
