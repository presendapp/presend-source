How it works

Microsoft Office files contain extensive metadata in their core.xml files, including author name, company, creation date, modification history, and even previous author names. When you share these documents, this metadata is exposed. Our tool opens the Office package, removes all identifying metadata, and repackages the file.

In a multi-team or client setting

A document that's passed through legal, then marketing, then an external agency accumulates a trail of author names and companies in its metadata — sending the final version to a client or the press without cleaning it can reveal internal team structure, which vendor drafted a section, or who reviewed what, none of which is meant for external eyes.

FAQ

Does this remove tracked changes and comments too?
It targets metadata fields (author, company, dates); for visible tracked changes and comments, make sure to accept/reject changes and delete comments in Word first, then run this tool for the remaining hidden metadata.

Is the document content or formatting altered?
No — only metadata is stripped, the visible document stays exactly as it was.
