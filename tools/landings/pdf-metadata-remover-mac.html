How it works

While macOS Preview can view some PDF metadata, it cannot remove all hidden fields such as the PDF producer, creation tool, or embedded XMP metadata. Our browser-based tool works on any Mac and removes every trace of metadata without requiring installation or registration.

Why Mac users often search for this

macOS doesn't ship a built-in way to strip PDF metadata — Preview lets you view and edit some fields under Tools → Show Inspector, but it won't clear the PDF producer string, embedded XMP data, or history left by Pages or third-party editors. Command-line tools like exiftool exist but require Terminal comfort most people don't want for a one-off task.

FAQ

Does this work on both Intel and Apple Silicon Macs?
Yes — since it runs entirely in your browser, it works identically regardless of your Mac's processor.

Do I need to install anything?
No. No app, plugin, or Terminal command is needed — just open the tool in Safari, Chrome, or any modern browser.
