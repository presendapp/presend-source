How it works

When you export a document to PDF, it automatically embeds metadata such as the author's name, the organization, the software version, and creation dates. This information can be read by anyone who receives the file. Our browser-based tool removes all embedded metadata permanently.

For legal and official documents

Court filings, FOIA requests, whistleblower submissions, and public records disclosures have specific reasons to strip metadata — the software version and creation timestamp embedded in a PDF has, in real cases, been used to identify a document's true origin or contradict a stated timeline, even when the visible content gave nothing away.

FAQ

Does this remove metadata added by digital signatures?
Standard metadata fields are stripped; if your PDF has a certified digital signature, removing metadata may invalidate that signature since it changes the file — sign after cleaning, not before.

Is this enough to fully anonymize a document?
Metadata removal covers the file's embedded properties, not identifying information within the visible text itself — review the content separately if full anonymity is required.
