How does it work?

This tool uses a curated multilingual wordlist and heuristic rules running entirely in your browser. It detects toxic language (insults, slurs), spam patterns (excessive caps, repeated characters, suspicious keywords), and risky links (URL shorteners, phishing domains, IP-based URLs). No text is ever sent to our servers — the analysis happens locally via JavaScript.
