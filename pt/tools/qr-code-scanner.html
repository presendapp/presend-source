Como funciona a leitura de código QR?

Os códigos QR codificam dados usando uma grade de quadrados pretos e brancos que um scanner lê para reconstruir o texto original, link ou detalhes de contato. Nosso QR Code Scanner decodifica isso diretamente em seu navegador usando processamento de imagem JavaScript – nenhuma imagem é carregada em um servidor e nenhuma filmagem de câmera é transmitida ou armazenada. Você pode fazer upload de uma foto ou captura de tela contendo um código QR ou usar a câmera do seu dispositivo para digitalizar um ao vivo. Isso é especialmente útil para verificar um código QR desconhecido antes de abrir o link que ele contém ou para ler códigos QR de materiais impressos, telas ou documentos. O conteúdo decodificado é exibido instantaneamente como texto simples, pronto para copiar ou clicar se for um URL.
