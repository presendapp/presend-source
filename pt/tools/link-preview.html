Como funciona?

Quando você insere uma URL, nosso proxy do lado do servidor busca o conteúdo da página em seu nome — contornando as restrições de CORS do navegador. Em seguida, ele analisa o HTML para extrair tags Open Graph (og:title, og:description, og:image, og:site_name) e recorre a tags HTML padrão quando os dados OG estão ausentes. Os metadados extraídos são retornados como JSON estruturado e exibidos como um cartão de pré-visualização visual. O Presend não guarda a URL (seu IP pode ser mantido por até 2 minutos como chave de limitação de requisições). O site consultado vê uma requisição vinda do servidor do Presend, e depois seu navegador carrega a imagem de pré-visualização e o favicon diretamente desse site, que portanto também vê seu IP.
