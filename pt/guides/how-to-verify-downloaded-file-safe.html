Como verificar se um arquivo baixado é seguro

Quando você baixa software, um documento ou qualquer arquivo da internet, como sabe que é o verdadeiro? Uma das formas mais confiáveis é verificar sua soma de verificação criptográfica.

O que é uma soma de verificação?

Uma soma de verificação é uma cadeia de caracteres única gerada a partir do conteúdo de um arquivo. Se mesmo um único byte mudar — por corrupção ou adulteração maliciosa — a soma de verificação muda completamente. SHA-256 é o padrão da indústria para esta verificação.

Como verificar SHA-256

O publicador do arquivo geralmente fornece o hash SHA-256 esperado. Você calcula o hash do arquivo baixado e compara os dois. Se corresponderem exatamente, o arquivo está intacto. Use nosso verificador de hash de arquivos para calcular SHA-256, SHA-1 e SHA-512 instantaneamente no seu navegador.

Sinais de alerta para observar

Se a soma de verificação não corresponder, não abra o arquivo. Exclua-o e baixe novamente da fonte oficial. Tenha especial cuidado com executáveis, PDFs de remetentes desconhecidos e arquivos de redes peer-to-peer.

Por que fazer isso no navegador?

Nossa ferramenta funciona inteiramente no seu dispositivo. Seu arquivo nunca é enviado para um servidor, o que é crítico quando você lida com downloads sensíveis ou confidenciais.
