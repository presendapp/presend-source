À propos de Presend

Presend est une petite collection d'utilitaires rapides qui fonctionnent dans le navigateur, pour nettoyer, compresser et préparer vos fichiers avant de les partager. Les outils de fichiers s'exécutent localement dans votre navigateur et n'envoient jamais vos fichiers. Certains autres outils font appel à notre API ou à un service en ligne ; ils sont indiqués dans la politique de confidentialité.

Source ouverte

Le code est disponible sur GitHub. N'hésitez pas à l'examiner, à en faire un fork ou à contribuer.
