Comment ça marche ?

Lorsque vous saisissez une URL, notre proxy côté serveur récupère le contenu de la page à votre place — en contournant les restrictions CORS du navigateur. Il analyse ensuite le HTML pour extraire les balises Open Graph (og:title, og:description, og:image, og:site_name) et se rabat sur les balises HTML standard si les données OG sont absentes. Les métadonnées extraites sont renvoyées sous forme de JSON structuré et affichées sous forme de carte d'aperçu visuelle. Presend ne conserve pas l'URL (votre IP peut être gardée jusqu'à 2 minutes comme clé de limitation de débit). Le site consulté voit une requête venant du serveur de Presend, puis votre navigateur charge l'image d'aperçu et le favicon directement depuis ce site, qui voit donc aussi votre IP.
