Comment fonctionne la numérisation de code QR ?

Les codes QR codent les données à l'aide d'une grille de carrés noirs et blancs qu'un scanner lit pour reconstruire le texte, le lien ou les coordonnées d'origine. Notre scanner de code QR décode cela directement dans votre navigateur à l'aide du traitement d'image JavaScript : aucune image n'est jamais téléchargée sur un serveur et aucune séquence de caméra n'est jamais transmise ou stockée. Vous pouvez soit télécharger une photo ou une capture d'écran contenant un code QR, soit utiliser l'appareil photo de votre appareil pour en scanner une en direct. Ceci est particulièrement utile pour vérifier un code QR inconnu avant d'ouvrir le lien qu'il contient, ou pour lire des codes QR à partir de documents imprimés, d'écrans ou de documents. Le contenu décodé s'affiche instantanément sous forme de texte brut, prêt à être copié ou cliqué s'il s'agit d'une URL.
