Comment supprimer les métadonnées avant le partage

Chaque fichier que vous créez ou modifiez contient des métadonnées invisibles — votre nom, vos coordonnées GPS, le logiciel utilisé et des horodatages. Avant d'envoyer un fichier par email, de le mettre en ligne ou de le publier, il est prudent de supprimer ces données. Voici comment le faire en toute sécurité et confidentialité.

1. Photos : supprimer les données EXIF et GPS

Quand vous prenez une photo avec votre téléphone, il intègre des données EXIF incluant la localisation GPS exacte, le modèle d'appareil photo, et la date et l'heure où la photo a été prise. Utilisez notre suppresseur EXIF pour tout retirer en un clic. L'image est redessinée localement dans votre navigateur — rien n'est téléchargé.

2. PDFs: Clear author and software info

Les PDF stockent souvent le nom de l'auteur, le logiciel utilisé pour les créer et les dates de création. Notre outil de suppression des métadonnées PDF efface toutes les informations standard du document avant que vous ne partagiez le fichier.

3. Office documents: Strip edit history

Les fichiers Word, Excel et PowerPoint peuvent contenir l'historique des révisions, les noms d'auteur, les informations d'entreprise et les commentaires. Utilisez l'outil de suppression des métadonnées Office pour les nettoyer.

4. Videos: Remove GPS and device data

Les vidéos MP4 et MOV enregistrées sur les smartphones peuvent contenir des coordonnées GPS et des informations sur le modèle de l'appareil. Le outil de suppression des métadonnées vidéo retire ces métadonnées sans réencoder la vidéo.

Pourquoi c'est important

Les métadonnées peuvent révéler où vous vivez, où vous travaillez, quel appareil vous utilisez et quand vous avez créé un fichier. Pour les journalistes, les militants, les avocats ou quiconque valorise la vie privée, supprimer les métadonnées est une étape d'hygiène de base avant de partager des fichiers publiquement.
