¿Cómo funciona?

Esta herramienta usa la conexión de tu navegador a nuestro servidor, que detecta tu dirección IP pública mediante encabezados HTTP estándar (CF-Connecting-IP). La ubicación, la zona horaria y el operador de red provienen de los datos que Cloudflare adjunta a cada solicitud (request.cf): no se llama a ningún servicio de geolocalización de terceros. La IP también se compara con la lista pública de nodos de salida de Tor. Tu IP puede conservarse hasta 2 minutos como clave de limitación de solicitudes, y Presend no la almacena de ninguna otra forma. El mapa se dibuja con teselas de OpenStreetMap, que tu navegador descarga directamente de los servidores de OpenStreetMap: estos ven tu IP y la zona mostrada.
