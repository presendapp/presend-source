Cómo comprobar si se violó su contraseña

Las violaciones de datos exponen miles de millones de contraseñas cada año. A continuación le mostramos cómo verificar si la suya está entre ellas, sin tener que enviar su contraseña real a nadie.

El problema de los verificadores de infracciones tradicionales

La mayoría de los sitios web que afirman verificar si se violó su contraseña le piden que la escriba en un formulario. Ese formulario envía su contraseña a su servidor. Incluso si el sitio es confiable, ahora confías en:

  • La seguridad de su servidor
  • Sus prácticas de tala
  • Sus empleados e infraestructura.
  • Que ellos mismos no serán violados

Esto es al revés. No debería tener que confiarle a nadie su contraseña para verificar si se filtró.

¿Qué es el k-anonimato?

k-anonimatoes una técnica de preservación de la privacidad que le permite comparar una contraseña con una base de datos sin revelar la contraseña en sí. Así es como funciona:

  1. Su contraseña está codificada usando SHA-1 localmente en su navegador
  2. Sólo elprimeros 5 caracteresdel hash se envían a la API de Have I Been Pwned
  3. La API devuelve una lista de sufijos hash que coinciden con esos 5 caracteres.
  4. Su navegador comprueba localmente si su hash completo aparece en esa lista

El servidor nunca ve suficiente información para reconstruir su contraseña. Incluso si la API está comprometida o se registran solicitudes, lo peor que le pasa a un atacante es que el hash de su contraseña comience con un prefijo determinado, que se aplica a millones de contraseñas.

¿Por qué utilizar el verificador de Presend?

  • Hash local— El hash SHA-1 se calcula en su navegador, no en nuestro servidor
  • Sin registro— No vemos su contraseña ni siquiera el prefijo hash
  • Enfoque de código abierto— El JavaScript es visible y auditable.
  • No se necesita cuenta— Verifica tantas contraseñas como quieras, de forma anónima

¿Qué pasa si mi contraseña fue violada?

Si el verificador descubre que su contraseña ha sido infringida:

  1. cambiarlo inmediatamenteen cada servicio donde lo utilices
  2. Nunca reutilices contraseñas— Utilice una contraseña única para cada cuenta
  3. Utilice un administrador de contraseñas— Herramientas como Bitwarden, 1Password o KeePass generan y almacenan contraseñas seguras y únicas.
  4. Habilitar 2FA— La autenticación de dos factores agrega una segunda capa crítica de seguridad
