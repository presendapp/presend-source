テキスト読み上げ

テキストを入力または貼り付けると、読み上げます。ブラウザ内蔵の音声エンジンを使用します。Presend がテキストを受け取ることはなく、端末の音声ならテキストは端末内に留まります。一覧で「オンライン」と表示された音声は、テキストを Google または Microsoft に送信します。

あなたのテキストが当社のサーバーに送信されることはありません

この音声はオンラインで動作します。読み上げのため、テキストは Google または Microsoft に送信されます。テキストを端末内に留めるには、「オンライン」表示のない音声を選ぶか、上の AI 音声をオンにしてください（ブラウザ内だけで動作します）。

準備ができて

ヒント：音声をファイルとして保存するには、再生中にOS標準の画面/音声レコーダーを使用してください（Windows: Win+G、macOS: Cmd+Shift+5）。

どのように機能するのでしょうか?

このツールは、Web Speech API の speechSynthesis インターフェイス、すべての最新ブラウザで利用できるネイティブのブラウザ機能を使用しています。音声は OS が提供します。Windows では Microsoft の音声、macOS では Siri 品質の音声、Android や iOS では端末ネイティブの音声エンジンです。Presend がテキストを受け取ることはありません。システムの音声は端末上で生成されます。一部のブラウザはオンライン音声（Chrome の Google 音声、Edge の Microsoft「Online (Natural)」音声）も提供しており、これらはテキストを提供元に送信します。音声一覧では「オンライン」と表示されます。ブラウザには speechSynthesis の出力を直接取り込む API がないため、音声を保存するには再生中に OS の画面録画または録音機能を使うか、WAV をダウンロードできる AI 音声を選んでください。
