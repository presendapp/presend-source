MP3/M4A から ID3 タグとメタデータを削除する方法

オーディオ ファイルには音声だけではありません。内部には ID3 タグ、アルバム アート、そして場合によっては GPS 座標やソフトウェアの指紋が隠されています。再エンコードせずにすべてを削除する方法は次のとおりです。

オーディオ ファイルにはどのようなメタデータが隠されていますか?

DAW から曲をエクスポートしたり、CD をリッピングしたり、ポッドキャストをダウンロードしたりすると、多くの場合、結果のファイルには埋め込みメタデータが含まれます。

  • ID3v2タグ— タイトル、アーティスト、アルバム、ジャンル、トラック番号、年、歌詞
  • ID3v1タグ— 基本情報を含む従来の 128 バイトのフッター
  • アルバムアートワーク— 埋め込まれた JPEG または PNG 画像 (サイズが大きい場合があります)
  • iTunes メタデータ— 購入日、アカウント名、Apple ID
  • ソフトウェアのフィンガープリント— ファイルを作成した DAW またはエンコーダー
  • コメント欄— 多くの場合、メモ、URL、または個人的なメッセージが含まれます

オーディオメタデータを削除する理由は何ですか?

  • プライバシー— あなたの名前、ソフトウェアライセンス、または購入履歴が埋め込まれる可能性があります
  • ファイルサイズ— アルバムアートと大きなコメントブロックはメガバイトを追加する可能性があります
  • プロフェッショナルな共有— 個人情報を添付せずにクリーンなデモを送信します
  • ポッドキャスト配信— 一部のプラットフォームでは、特定のメタデータを含むファイルが拒否されます
  • 法医学的な清潔さ— 識別できる痕跡が残らないようにする

仕組み (再エンコードなし)

Presend の Audio Metadata Remover はバイト レベルで動作します。

  1. MP3ファイル— ID3v2 ヘッダー (開始時) と ID3v1 フッター (終了時) を検出して削除し、その間の生の MPEG オーディオ フレームを保持します。
  2. M4Aファイル— MP4 コンテナ構造を解析し、メタデータ アトム (ilst、meta、udta) を識別し、それらを含まずにファイルを再構築します。

メタデータ コンテナのみを削除し、音声データには触れないため、品質損失はゼロです。オーディオのサウンドはまったく同じで、よりクリーンになっています。

ステップバイステップのガイド

  1. ツールを開く— に移動オーディオメタデータリムーバー
  2. ファイルをアップロードする— ドラッグ アンド ドロップまたはクリックして MP3 または M4A を選択します
  3. 見つかったメタデータを確認する— このツールは、発見した内容 (アーティスト、タイトル、アルバム アートのサイズなど) を表示します。
  4. クリーンなファイルをダウンロードする— 同じオーディオ品質、メタデータなし

他の形式についてはどうですか?

現在サポートされているもの:MP3(ID3v1 および ID3v2) およびM4A(iTunes/Apple 形式)。 FLAC、OGG、WMAのサポートが予定されています。 WAV ファイルの場合、メタデータはまれですが、一般的なファイル ツールを使用して削除できます。
