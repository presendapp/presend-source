無料で音声をテキストに書き写す方法

ボイスメモや会議の録音、口述したメモをテキストにしたいですか？ブラウザでできます。サブスクリプションもアカウントも不要で、Presendには何もアップロードされません。

なぜブラウザベースの文字起こしをするのでしょうか?

Otter.ai、Rev、Trint などの人気の文字起こしサービスでは、音声をクラウド サーバーにアップロードする必要があります。これにより、次のようないくつかの問題が発生します。

  • プライバシー — クラウドの文字起こしサービスは、他社のサーバーで音声を処理します。ChromeとEdgeのブラウザ音声認識も同じなので、このページはプライバシー保護にはなりません。
  • 料金— ほとんどのサービスは、月単位のサブスクリプションまたは分単位の料金を請求します。
  • 遅れ— アップロード + 処理 + ダウンロードに時間がかかります
  • アカウントが必要です— アカウントを作成し、利用規約に同意する必要があります

Web Speech API の仕組み

最新のブラウザには、ウェブスピーチAPI。何が起こるかというと、次のとおりです。

  1. ブラウザへのマイクアクセスを許可します
  2. ブラウザの音声サービスが音声をテキストに変換します。ChromeはGoogleのサーバーに、EdgeはMicrosoftのサーバーに送信し、SafariはAppleの音声認識を使用します
  3. 転写されたテキストはリアルタイムで Web ページにストリーミングされます。
  4. Presendのサーバーには何も送信されませんが、ブラウザの音声サービスは音声を受け取ります

サポートされている言語

言語サポートはブラウザとオペレーティング システムによって異なります。ほとんどのシステムは以下をサポートしています。

  • 英語 (米国、英国、オーストラリア、インド)
  • フランス語、スペイン語、ドイツ語、イタリア語、ポルトガル語
  • 日本語、韓国語、中国語（簡体字・繁体字）
  • アラビア語、ヒンディー語、ロシア語、オランダ語、ポーランド語、トルコ語

言語が利用できない場合、ブラウザはサポートされている最も近い言語にフォールバックします。

精度のためのベストプラクティス

  • 良いマイクを使う— ラップトップの内蔵マイクも機能しますが、USB ヘッドセットまたは専用マイクを使用すると精度が大幅に向上します
  • 背景ノイズを最小限に抑える— 静かな部屋ではより鮮明なトランスクリプトが作成されます
  • はっきりと話す— 一貫した音量を発音し維持する
  • 文と文の間で一時停止する— エンジンがテキストを正しくセグメント化するのに役立ちます
  • 句読点をチェックする— API は句読点を自動的に挿入しますが、編集が必要な場合があります。

制限事項

  • Firefox音声認識はサポートしていません (合成のみ)。 Chrome、Edge、または Safari を使用してください。
  • 長いセッション一部のブラウザでは 60 秒後にタイムアウトする場合があります。この問題が発生した場合は、単純に再起動してください。
  • アクセントと方言あまり一般的ではないバリアントの精度が低下する可能性があります。
  • 専門用語（医療、法律、技術）後編集が必要な場合があります。
  • 機密性の高い音声には不向き — ChromeとEdgeでは音声が端末の外に送信されます。医療、法律、その他の機密の口述には、オフラインの文字起こしツールを使ってください。

ステップバイステップのガイド

  1. ツールを開く— に移動音声からテキストへの変換
  2. 言語を選択してください— ドロップダウン メニューから選択します
  3. 「リスニングを開始」をクリックします— プロンプトが表示されたらマイクへのアクセスを許可します
  4. 自然に話す— 話すとテキストが表示されます
  5. 「停止」をクリックします終わったら
  6. コピーまたはダウンロード— .txt ファイルとして保存するか、クリップボードにコピーします
