スクリーンショットをテキストに変換

画像またはスクリーンショットからテキストをコピーします。 Tesseract.js は完全にブラウザ内で実行されます。画像はアップロードされません。

あなたの画像が当社のサーバーに送信されることはありません

ここにスクリーンショットをドロップするか、クリックしてスクリーンショットを選択してください

Tesseract.js はどのように機能しますか?

このツールが使用するのは、Tesseract.js、WebAssembly にコンパイルされた Google の Tesseract OCR エンジンの純粋な JavaScript ポートです。言語モデル (英語の場合は最大 4MB) が一度ダウンロードされ、ブラウザーにキャッシュされます。すべてのテキスト認識はデバイス上でローカルに行われます。画像データが当社のサーバーに送信されることはありません。これは、クラウド OCR サービスには決してアップロードしたくない医療記録、法的契約書、財務諸表、独自のスクリーンショットなどの機密文書にとって重要です。 Tesseract.js は 100 以上の言語をサポートし、クリアでハイコントラストなテキストで商用クラウド API に匹敵する精度を実現します。
