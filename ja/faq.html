よくある質問

写真をアップロードせずにEXIFデータを削除したらどうですか?

Presend の EXIF Remover は、HTML5 Canvas API を使用してブラウザ内で完全に実行されます。画像は自分のデバイスで処理され、サーバーに送信されることはありません。写真をアンドドロップするだけで、クリーンなバージョンが即座にダウンロードされます。

PDFメタデータをオンラインで削除しても安全ですか?

ほとんどのオンライン PDF ツールはファイルをリモート サーバーにアップロードするため、プライバシー リスクが生じます。 事前送信は、ブラウザ内でローカルに PDF を処理します。pdf-libドキュメントがデバイスから離れることはなく、PDF から作成者名、ソフトウェア バージョン、作成日を削除するのが最も安全な方法です。

写真から削除される EXIFデータは何ですか?

Presend は、GPS 公認、カメラのメーカーとモデル、写真が撮影された日時、レンズ情報、編集ソフトウェア履歴を含むすべての埋め込みメタデータを削除します。出力はメタデータのないきれいな JPEG または PNG です。

Presend は私のファイルのコピーを保存しますか?

いいえ。Presendにはバックエンド、ユーザー データベース アカウントがありません。ファイルはブラウザ タブ内のメモリ内で処理されます。タブを閉じるかページを更新すると、何も残りません。ファイルにアクセスしたくてもアクセスできません。

Presendは無料で使えますか?

はい、Presend は完全に無料で、MIT ライセンスに基づくオープン ソースです。ペイウォール、登録要件、使用制限はありません。

ファイルを共有する前にメタデータを削除する必要があるのはなぜですか?

写真により、GPSによる正確な位置、しているすべてのカメラ、写真を撮影した時間がなくなります。 PDF では、作成に使用したソフトウェア、作成者の名前、内部の改訂履歴が公開される可能性があります。共有する前にこのメタデータを削除すると、プライバシーと運用上のセキュリティが保護されます。
