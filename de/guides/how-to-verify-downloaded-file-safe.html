Überprüfen, ob eine heruntergeladene Datei sicher ist

Wenn Sie Software, ein Dokument oder eine beliebige Datei aus dem Internet herunterladen, wie wissen Sie, dass sie echt ist? Eine der zuverlässigsten Methoden ist die Überprüfung der kryptografischen Prüfsumme.

Was ist eine Prüfsumme?

Eine Prüfsumme ist eine eindeutige Zeichenkette, die aus dem Inhalt einer Datei generiert wird. Wenn sich auch nur ein einziges Byte ändert — durch Beschädigung oder böswillige Manipulation — ändert sich die Prüfsumme vollständig. SHA-256 ist der Industriestandard für diese Überprüfung.

So überprüfen Sie SHA-256

Der Herausgeber der Datei stellt normalerweise den erwarteten SHA-256-Hash bereit. Sie berechnen den Hash der heruntergeladenen Datei und vergleichen die beiden. Wenn sie exakt übereinstimmen, ist die Datei intakt. Nutzen Sie unseren Datei-Hash-Prüfer, um SHA-256, SHA-1 und SHA-512 sofort in Ihrem Browser zu berechnen.

Warnsignale, auf die Sie achten sollten

Wenn die Prüfsumme nicht übereinstimmt, öffnen Sie die Datei nicht. Löschen Sie sie und laden Sie sie erneut von der offiziellen Quelle herunter. Seien Sie besonders vorsichtig mit ausführbaren Dateien, PDFs von unbekannten Absendern und Dateien aus Peer-to-Peer-Netzwerken.

Warum im Browser?

Unser Tool läuft vollständig auf Ihrem Gerät. Ihre Datei wird niemals auf einen Server hochgeladen, was entscheidend ist, wenn Sie mit sensiblen oder vertraulichen Downloads zu tun haben.
