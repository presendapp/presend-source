● Presend

Presend API für Entwickler

Kostenlose Server-Endpoints für gängige Aufgaben, plus einbettbare clientseitige Tools. Kein API-Key nötig. Keine Registrierung.

Server-Endpoints

Laufen im Cloudflare-Edge-Netzwerk und liefern JSON zurück. Nur faire Nutzung — kein offizielles SLA, starker oder automatisierter Traffic kann ohne Vorwarnung gedrosselt werden.

Python-Nutzer: Anfragen mit dem Standard-User-Agent von urllib (Python-urllib/3.x) werden von Cloudflare mit HTTP 403 und dem Body error code: 1010 abgelehnt. Setzen Sie einen beliebigen expliziten User-Agent. requests, curl und Node senden einen, der akzeptiert wird. 

import json, urllib.request
req = urllib.request.Request("https://presend.pages.dev/api/uuid", headers={"User-Agent": "my-app/1.0"})
print(json.load(urllib.request.urlopen(req)))

POST /api/hash

Gibt SHA-256, SHA-1 und SHA-512 für jede Datei bis 20 MB zurück.

curl -X POST --data-binary @file.pdf \
  https://presend.pages.dev/api/hash

# {"size_bytes":17,"hashes":{"sha256":"...","sha1":"...","sha512":"..."}}

POST /api/file-type

Erkennt den tatsächlichen Dateityp anhand der binären Signatur und meldet eine Abweichung vom angegebenen Content-Type – erkennt getarnte Dateien (z. B. eine als Foto umbenannte ausführbare Datei), die naive Upload-Filter passieren.

curl -X POST --data-binary @suspicious.jpg -H "Content-Type: image/jpeg" https://presend.pages.dev/api/file-type

POST /api/malware-check

Hasht eine hochgeladene Datei (SHA-256) und prüft sie gegen MalwareBazaar (abuse.ch), eine kostenlose Datenbank bekannter Malware-Samples – Hash und Prüfung in einem Aufruf.

curl -X POST --data-binary @file.exe https://presend.pages.dev/api/malware-check

GET /api/url-clean

Entfernt über 60 Tracking-Parameter (utm_*, fbclid, gclid...) aus einer URL.

curl "https://presend.pages.dev/api/url-clean?url=https://example.com/?utm_source=x"

# {"clean":"https://example.com/","removed":1,"valid":true}

POST /api/url-clean

Dasselbe als Batch – bis zu 100 URLs pro Anfrage.

curl -X POST -H "Content-Type: application/json" \
  -d '{"urls":["https://a.com?fbclid=x","https://b.com?gclid=y"]}' \
  https://presend.pages.dev/api/url-clean

GET /api/ip

Gibt die IP des Aufrufers mit Geolokalisierung, Währung, Sprache sowie EU- und VPN-Kennzeichen zurück.

curl https://presend.pages.dev/api/ip

GET /api/uuid

Erzeugt zufällige UUIDs (v4), bis zu 100 pro Anfrage.

curl "https://presend.pages.dev/api/uuid?count=5"

GET /api/base64

Kodiert oder dekodiert Base64-Text.

curl "https://presend.pages.dev/api/base64?action=encode&text=hello"

GET /api/jwt-decode

Dekodiert Header und Payload eines JWT (ohne die Signatur zu prüfen; dafür jwt-verify verwenden).

curl "https://presend.pages.dev/api/jwt-decode?token=eyJhbGci..."

POST /api/jwt-verify

Prüft tatsächlich die kryptografische Signatur eines JWT (HS256/384/512, RS/PS256/384/512, ES256/384/512) über die native Web Crypto API der Workers – plus Prüfung der Claims exp/nbf. Geben Sie ein „secret“ für HMAC an, oder ein „jwk“/„jwks_url“ für asymmetrische Algorithmen.

curl -X POST -H "Content-Type: application/json" -d '{"token":"...","secret":"..."}' https://presend.pages.dev/api/jwt-verify

GET /api/timestamp

Aktuelle Zeit, oder Umrechnung zwischen Unix-Zeitstempel und ISO-Datum.

curl "https://presend.pages.dev/api/timestamp?unix=1700000000"

GET /api/color

Konvertiert zwischen den Farbformaten Hex, RGB und HSL.

curl "https://presend.pages.dev/api/color?hex=ff5733"

GET /api/user-agent

Zerlegt einen User-Agent-String in Browser, Betriebssystem und Gerätetyp.

curl "https://presend.pages.dev/api/user-agent"

GET /api/password

Erzeugt ein kryptografisch sicheres Passwort mit Entropie-Schätzung.

curl "https://presend.pages.dev/api/password?length=20&symbols=1"

GET /api/email-validate

Prüft die Syntax einer E-Mail-Adresse und ob die Domain einen MX-Eintrag hat. Das Postfach wird nicht abgefragt, die Existenz der Adresse kann also nicht bestätigt werden; nutzen Sie email-verify, um zusätzlich Wegwerf-Domains und Rollenkonten zu erkennen.

curl "https://presend.pages.dev/api/email-validate?email=foo@example.com"

GET /api/favicon

Ermittelt die Favicon-URL einer beliebigen Domain.

curl "https://presend.pages.dev/api/favicon?domain=github.com"

GET/POST /api/csv-json

Konvertiert zwischen JSON und CSV. Verschachtelte Objekte werden als Zeichenkette ausgegeben, nicht abgeflacht.

curl -X POST -H "Content-Type: application/json" \
  -d '{"direction":"json-to-csv","data":"[{\"a\":1}]"}' \
  https://presend.pages.dev/api/csv-json

GET /api/password-breach

Prüft, ob ein Passwort in bekannten Datenlecks vorkommt (Have I Been Pwned). Nur die ersten 5 Zeichen seines SHA-1-Hashes werden an HIBP gesendet (k-Anonymität), und Presend protokolliert es nicht. Da es sich aber um eine GET-Anfrage handelt, steht das Passwort in der URL, wo Browser, Proxys oder Server-Logs es aufzeichnen können: für echte Passwörter POST /api/password-check verwenden.

curl "https://presend.pages.dev/api/password-breach?password=..."

POST /api/password-check

Kombiniert Stärke-/Entropie-Bewertung mit einer optionalen Leak-Prüfung in einem einzigen Aufruf — das Passwort wird im POST-Body übertragen, niemals in einer URL. Gleiche k-Anonymitätsgarantie wie password-breach.

curl -X POST -H "Content-Type: application/json" -d '{"password":"..."}' https://presend.pages.dev/api/password-check

GET /api/email-disposable

Erkennt Wegwerf-E-Mail-Anbieter anhand einer Liste von über 576 bekannten Domains.

curl "https://presend.pages.dev/api/email-disposable?email=foo@mailinator.com"

GET /api/email-verify

Kombiniert Syntaxprüfung, MX-Abfrage, Erkennung von Wegwerf-Domains und Erkennung generischer Konten (info@, admin@...) in einem einzigen Aufruf .

curl "https://presend.pages.dev/api/email-verify?email=foo@example.com"

GET /api/phone-verify

Validiert und formatiert eine Telefonnummer (E.164, international, national) über libphonenumber-js. Wenn für eine Nummer ohne „+“-Präfix kein Land angegeben ist, wird automatisch das aus der IP abgeleitete Land des Anrufers verwendet.

curl "https://presend.pages.dev/api/phone-verify?number=%2B14155552671"

GET /api/email-security

Prüft die E-Mail-Konfiguration einer Domain gegen Spoofing: SPF-Stärke, DMARC-Richtlinie und eine Best-Effort-DKIM-Abfrage für gängige Selektoren.

curl "https://presend.pages.dev/api/email-security?domain=example.com"

GET /api/security-scan

Kombiniert security-headers, url-reputation und subdomains in einem Bericht mit Gesamtpunktzahl und Urteil – ein Aufruf statt drei.

curl "https://presend.pages.dev/api/security-scan?url=https://example.com"

POST /api/qr-scan

Dekodiert einen QR-Code aus einem hochgeladenen Bild und prüft eine enthaltene URL gegen URLhaus auf Malware- und Phishing-Hinweise – Dekodierung und Reputationsprüfung in einem Aufruf. QR-Code-Phishing („Quishing“) gehört zu den am schnellsten wachsenden Phishing-Methoden.

curl -X POST -F "file=@qrcode.png" https://presend.pages.dev/api/qr-scan

GET /api/security-headers

Prüft HTTP-Sicherheitsheader (CSP, HSTS, X-Frame-Options...) und vergibt eine Buchstabennote.

curl "https://presend.pages.dev/api/security-headers?url=https://example.com"

GET /api/url-reputation

Prüft eine URL gegen URLhaus, eine öffentliche Datenbank für Malware und Phishing.

curl "https://presend.pages.dev/api/url-reputation?url=https://example.com"

GET /api/subdomains

Passive Subdomain-Erkennung über Certificate-Transparency-Logs (crt.sh) – zur Prüfung Ihrer eigenen Angriffsfläche. Hinweis: hängt von crt.sh ab, das gelegentlich ausfällt, außerhalb unserer Kontrolle.

curl "https://presend.pages.dev/api/subdomains?domain=example.com"

GET /api/ai-crawler-check

Ruft robots.txt ab und zeigt, welche bekannten KI-Crawler (GPTBot, ClaudeBot, PerplexityBot, Google-Extended, CCBot usw.) erlaubt oder blockiert sind. Kostenlos, keine Anmeldung nötig.

curl "https://presend.pages.dev/api/ai-crawler-check?domain=example.com"

GET /api/ip-reputation

Prüft eine IPv4- oder IPv6-Adresse gegen eine kuratierte Liste von Netzblöcken, die bekanntermaßen gekapert sind oder von Spam- bzw. Cybercrime-Akteuren kontrolliert werden. Eine bestimmte Liste, kein vollständiger Reputationswert. Die Kopie wird höchstens einmal täglich aktualisiert; die Antwort enthält das Datum der Liste, die Quellenangabe und ein stale-Flag, falls die Quelle so lange nicht erreichbar war, dass die Kopie älter als 48 Stunden ist. Für eine Prüfung bei jeder Anfrage in Ihrer eigenen Middleware ist es meist besser, die Liste lokal zu laden.

curl "https://presend.pages.dev/api/ip-reputation?ip=1.2.3.4"

GET /api/dns-lookup

A-, AAAA-, CNAME-, MX-, TXT- und NS-Einträge in einem Aufruf über den DNS-over-HTTPS-Resolver von Cloudflare, oder ein einzelner Typ mit type=.

curl "https://presend.pages.dev/api/dns-lookup?domain=example.com"

GET /api/whois-lookup

Registrar, Erstellungs- und Ablaufdatum, Alter der Domain und Nameserver über RDAP, den HTTPS-basierten Nachfolger des klassischen WHOIS.

curl "https://presend.pages.dev/api/whois-lookup?domain=example.com"

GET /api/redirect-trace

Folgt der vollständigen Weiterleitungskette einer URL (bis zu 15 Schritte) und erfasst für jeden Schritt Statuscode und Ziel, nicht nur die endgültige URL.

curl "https://presend.pages.dev/api/redirect-trace?url=http://github.com"

Lieferketten-Sicherheit

Prüfungen von Abhängigkeitsrisiken. typosquat-check und maintainer-change-check sind Heuristiken: Signale zur Sichtung, keine Urteile.

GET /api/typosquat-check

Meldet Paketnamen, die einem Namen aus einer kuratierten Liste bekannter npm- und PyPI-Pakete sehr ähnlich sind (1 Änderung bei 4–7 Zeichen, 2 ab 8; Namen mit 3 Zeichen oder weniger werden nicht unscharf verglichen). PyPI-Namen werden normalisiert (PEP 503); geprüfte legitime Doppelgänger sind mit known_legitimate markiert.

curl "https://presend.pages.dev/api/typosquat-check?ecosystem=npm&package=lodahs"

POST /api/typosquat-check

Batch-Modus: bis zu 100 Namen pro Anfrage, für das Rate-Limit als eine einzige Anfrage gezählt. Ein ungültiger Eintrag liefert einen Fehler für diesen Eintrag, ohne den Batch scheitern zu lassen.

curl -X POST -H "Content-Type: application/json" -d '{"ecosystem":"npm","packages":["lodahs","expres","react"]}' https://presend.pages.dev/api/typosquat-check

GET /api/maintainer-change-check

npm und PyPI. Bei npm meldet es, wenn ein bisher unbekannter menschlicher Publisher ein Paket nach über 180 Tagen Inaktivität übernimmt, innerhalb der letzten 365 Tage: das Muster hinter der Kompromittierung von event-stream (2018). Übergaben an einen Publisher, der bereits ein anderes Paket mit über 100.000 wöchentlichen Downloads betreut, sowie der Wechsel zu npm Trusted Publishing werden getrennt gemeldet, ohne das Signal auszulösen. Ein gekapertes bestehendes Maintainer-Konto oder eine bösartige Version vom ursprünglichen Maintainer wird nicht erkannt, da sich die Publisher-Identität nicht ändert. Bei PyPI meldet es nur Existenz und Alter: PyPI gibt nicht an, wer welche Version veröffentlicht hat, daher liefert die Publisher-Analyse maintainer_analysis: "npm_only". In beiden Registries geben first_published und package_age_days das Alter des Pakets an, und new_package ist true für ein Paket, das vor weniger als 30 Tagen erstmals veröffentlicht wurde. Bei PyPI ist das Alter das der ältesten noch vorhandenen Datei: Gelöschte Versionen lassen ein Projekt jünger wirken.

curl "https://presend.pages.dev/api/maintainer-change-check?ecosystem=npm&package=lodash"

POST /api/maintainer-change-check

Batch-Modus: bis zu 20 Pakete aus einer Registry (npm oder PyPI) pro Anfrage, für das Rate-Limit als eine einzige Anfrage gezählt. Ein fehlendes Paket oder ein Registry-Fehler wird pro Eintrag gemeldet, ohne den Batch scheitern zu lassen.

curl -X POST -H "Content-Type: application/json" -d '{"ecosystem":"npm","packages":["lodash","express"]}' https://presend.pages.dev/api/maintainer-change-check

GET /api/vulnerability-check

Prüft eine Paketversion gegen OSV.dev: npm, PyPI, Go, crates.io, Maven, RubyGems, Packagist, NuGet. Um eine CVE- oder GHSA-Kennung direkt nachzuschlagen, nutzen Sie cve-lookup. Ohne Version werden Hinweise zu allen Versionen gezählt (scope). Bei npm und PyPI liefert ein Name, der nicht existiert, found: false und vulnerable: null, nie ein unbedenkliches Ergebnis.

curl "https://presend.pages.dev/api/vulnerability-check?ecosystem=npm&package=lodash&version=4.17.15"

GET /api/repo-health-check

Sterne, Forks, offene Issues, Lizenz, Archivstatus und Tage seit dem letzten Push eines GitHub-Repositorys, über die GitHub REST API.

curl "https://presend.pages.dev/api/repo-health-check?repo=lodash/lodash"

GET /api/supply-chain-check

Kombiniert maintainer-change-check (Publisher-Analyse, nur npm), vulnerability-check, typosquat-check und repo-health-check (Repository nach Möglichkeit aus den Registry-Metadaten ermittelt) in einem Aufruf mit Gesamturteil. Ein Paket, das vor weniger als 30 Tagen erstmals veröffentlicht wurde, erhält das Flag new_package, und das Gesamturteil ist dann mindestens review_recommended. Schwachstellen werden für den optionalen Parameter version geprüft, sonst für die zuletzt veröffentlichte Version (version_checked, version_source).

curl "https://presend.pages.dev/api/supply-chain-check?ecosystem=npm&package=lodash"

Blockchain

Kostenlose Tools für die Cosmos- und EVM-Ökosysteme. Keine Anmeldung, kein API-Schlüssel.

GET /api/address-risk

Prüft eine Krypto-Adresse gegen alle OFAC-Listen digitaler Währungsadressen der Specially Designated Nationals (SDN). EVM- (0x...) und Bitcoin-Adressen (bc1..., 1..., 3...) sind vollständig abgedeckt; Adressen anderer Chains werden gemeldet, wenn sie gelistet sind. Cosmos-SDK-Adressen (bech32) liefern sanctioned: null, wenn sie nicht gelistet sind, da die OFAC keine Einträge für Cosmos-SDK-Chains veröffentlicht hat.

curl "https://presend.pages.dev/api/address-risk?address=0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2"

GET /api/tx-decode

Dekodiert eine rohe, signierte Cosmos-SDK-Transaktion (protobuf-TxRaw-Bytes, base64) in lesbares JSON -- Nachrichten, Gebühr, Gas, Signer-Infos, Signaturen. Ohne externe Abhängigkeit; dekodiert gängige Nachrichtentypen von bank/staking/gov/authz, einschließlich verschachtelter MsgExec.

curl "https://presend.pages.dev/api/tx-decode?tx=CpwBCpEBChwvY29zbW9zLmJhbmsudjFiZXRhMS5Nc2dTZW5kEnEK..."

GET /api/rpc-check

Prüft einen öffentlichen CometBFT-RPC-Endpunkt einer Cosmos-SDK-Chain: Knotenstatus, Zustand, Peer-Verbindungen und ob unsichere Verwaltungsmethoden (dial_seeds, dial_peers, unsafe_flush_mempool) offenbar erreichbar sind. Nur lesend -- ruft selbst niemals eine unsichere Methode auf.

curl "https://presend.pages.dev/api/rpc-check?url=https://cosmos-rpc.publicnode.com"

Hilfsprogramme

Kleine, fokussierte Tools, wo immer möglich ohne externe Abhängigkeit.

GET /api/iban-validate

Validiert eine IBAN über die Prüfsumme ISO 7064 mod-97, mit länderspezifischer Längenprüfung. Reiner Algorithmus -- keine externe Datenquelle.

curl "https://presend.pages.dev/api/iban-validate?iban=DE89370400440532013000"

GET /api/vat-validate

Validiert eine EU-USt-IdNr. in Echtzeit über den offiziellen VIES-Dienst der Europäischen Kommission -- liefert bei Gültigkeit den registrierten Firmennamen und die Adresse.

curl "https://presend.pages.dev/api/vat-validate?country=IE&vat=6388047V"

GET /api/link-metadata

Extrahiert Open-Graph-, Twitter-Card- und grundlegende <head>-Metadaten aus einer URL -- dieselben Daten, mit denen Chat-Apps eine Linkvorschau darstellen. Liefert außerdem das Favicon und, nach den Weiterleitungen (jede einzeln geprüft), die endgültige URL.

curl "https://presend.pages.dev/api/link-metadata?url=https://github.com/presendapp/presend-source"

GET /api/cve-lookup

Direkte CVE/GHSA-Abfrage per Kennung über OSV.dev. Ergänzt vulnerability-check (das Paket, Ökosystem und Version benötigt), wenn Sie bereits eine Kennung aus einem Scanner-Bericht haben.

curl "https://presend.pages.dev/api/cve-lookup?id=CVE-2021-44228"

Verkettete Workflows

Diese beiden Endpunkte verketten mehrere serverseitige Operationen in einem einzigen Aufruf . Die Verarbeitung ist zustandslos: Es wird nichts auf die Festplatte geschrieben, nichts protokolliert, die Datei wird sofort nach dem Senden der Antwort verworfen.

POST /api/merge-and-compress-pdf

Führt 2 oder mehr PDF-Dateien zu einem Dokument zusammen, komprimiert dann das Ergebnis und entfernt Metadaten (Titel, Autor, Ersteller) — in einer einzigen Anfrage statt zwei.

curl -X POST -F "files=@a.pdf" -F "files=@b.pdf" https://presend.pages.dev/api/merge-and-compress-pdf -o merged.pdf

POST /api/clean-image

Entfernt EXIF/GPS aus JPEG und Text-Metadaten aus PNG durch direktes Binär-Parsing — Pixel werden nie neu kodiert, daher kein Qualitätsverlust (im Gegensatz zu Canvas-basierten Ansätzen, die immer neu komprimieren).

curl -X POST --data-binary @photo.jpg -H "Content-Type: image/jpeg" https://presend.pages.dev/api/clean-image -o clean.jpg

POST /api/image-similarity

Wahrnehmungsbasierter Hash (dHash) für 1 oder 2 JPEG/PNG-Bilder. Anders als ein kryptografischer Hash übersteht er erneute Komprimierung und kleine Änderungen – senden Sie 2 Bilder, um sie direkt mit Ähnlichkeitswert und Urteil zu vergleichen.

curl -X POST -F "files=@a.jpg" -F "files=@b.png" https://presend.pages.dev/api/image-similarity

POST /api/text-similarity

SimHash für 1 oder 2 Texte – das Text-Gegenstück zu image-similarity. Erkennt umformulierte oder leicht bearbeitete Beinahe-Duplikate, anders als ein kryptografischer Hash. Unzusammenhängende Texte erreichen zufällig meist etwa 50 %, nicht 0 %.

curl -X POST -H "Content-Type: application/json" -d '{"texts":["text a","text b"]}' https://presend.pages.dev/api/text-similarity

Clientseitige Tools (einbetten)

Die meisten Tools zur Dateiverarbeitung (EXIF-Entfernung, PDF-Komprimierung usw.) laufen auch vollständig im Browser als eigenständige Widgets — dabei wird nichts hochgeladen. Nutzen Sie sie statt der API oben, wenn Sie eine fertige Oberfläche statt eines Serveraufrufs möchten. Direkt einbetten: 

<iframe 
  src="https://presend.pages.dev/tools/exif-remover?embed=1" 
  width="100%" 
  height="600" 
  frameborder="0"
></iframe>

Einbettbares Widget

Fügen Sie ein funktionierendes Tool direkt auf Ihrer Seite ein — ohne iframe, direkt von unserer API angetrieben. Unterstützt: url-cleaner, uuid, color. 

<div data-presend-tool="url-cleaner"></div>
<script src="https://presend.pages.dev/widget.js" async></script>

Fügen Sie data-badge="false" hinzu, um den „Powered by Presend"-Link auszublenden.
