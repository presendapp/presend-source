Wie funktioniert es?

Wenn du eine URL eingibst, ruft unser serverseitiger Proxy den Seiteninhalt in deinem Namen ab — und umgeht dabei die CORS-Beschränkungen des Browsers. Anschließend wird das HTML analysiert, um Open-Graph-Tags (og:title, og:description, og:image, og:site_name) zu extrahieren, und bei fehlenden OG-Daten wird auf Standard-HTML-Tags zurückgegriffen. Die extrahierten Metadaten werden als strukturiertes JSON zurückgegeben und als visuelle Vorschaukarte dargestellt. Presend speichert die URL nicht (deine IP kann bis zu 2 Minuten als Schlüssel für die Ratenbegrenzung gespeichert werden). Die geprüfte Website sieht eine Anfrage vom Server von Presend, und anschließend lädt dein Browser Vorschaubild und Favicon direkt von dieser Website, die damit auch deine IP sieht.
