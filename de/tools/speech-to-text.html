Wie funktioniert es?

Dieses Tool nutzt die Web-Sprach-API, eine Browserfunktion, die Sprache in Text umwandelt. Presend erhält Ihr Audio nie, aber der Browser kann es an seinen Anbieter senden: Chrome sendet es an Server von Google, Edge an Server von Microsoft. Unterstützung und Genauigkeit hängen von Browser und Betriebssystem ab. Für vertrauliche Gespräche, medizinische Notizen oder juristische Diktate verwenden Sie besser ein Offline-Transkriptionsprogramm.
