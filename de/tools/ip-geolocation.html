Entdecke deine öffentliche IP-Adresse, deinen ungefähren Standort, deine Zeitzone und deinen Internetanbieter. Dein Browser verbindet sich mit dem Server von Presend, der deine IP und ihren ungefähren Standort aus den Netzwerkdaten von Cloudflare liest; die Karte wird mit Kacheln von OpenStreetMap gezeichnet.

Wie funktioniert es?

Dieses Tool nutzt die Verbindung deines Browsers zu unserem Server, der deine öffentliche IP-Adresse über standardmäßige HTTP-Header (CF-Connecting-IP) erkennt. Standort, Zeitzone und Netzbetreiber stammen aus den Daten, die Cloudflare jeder Anfrage beifügt (request.cf): Es wird kein Geolokalisierungsdienst von Dritten aufgerufen. Die IP wird außerdem mit der öffentlichen Liste der Tor-Exit-Nodes abgeglichen. Deine IP kann bis zu 2 Minuten als Schlüssel für die Ratenbegrenzung gespeichert werden; darüber hinaus speichert Presend sie nicht. Die Karte wird mit Kacheln von OpenStreetMap gezeichnet, die dein Browser direkt von den Servern von OpenStreetMap lädt: Diese sehen deine IP und den angezeigten Bereich.
