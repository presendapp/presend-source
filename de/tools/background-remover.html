Wie funktioniert es?

Dieses Tool verwendet@imgly/background-removal, ein Modell für maschinelles Lernen, das in WebAssembly kompiliert und mit WebGL beschleunigt wird. Das Modell (~4 MB) wird einmal heruntergeladen und in Ihrem Browser zwischengespeichert. Die gesamte Bildverarbeitung erfolgt lokal auf Ihrer GPU oder CPU – es werden niemals Pixel an unsere Server übertragen. Dies unterscheidet sich grundlegend von Diensten wie „remove.bg“, die Ihr gesamtes Bild in die Cloud hochladen. Bei sensiblen Produktfotos, Ausweisdokumenten oder persönlichen Porträts garantiert die lokale Verarbeitung absolute Privatsphäre.
