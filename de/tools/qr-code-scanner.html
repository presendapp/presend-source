Wie funktioniert das Scannen von QR-Codes?

QR-Codes kodieren Daten mithilfe eines Rasters aus schwarzen und weißen Quadraten, die ein Scanner liest, um den ursprünglichen Text, Link oder die Kontaktdaten zu rekonstruieren. Unser QR-Code-Scanner dekodiert dies mithilfe der JavaScript-Bildverarbeitung direkt in Ihrem Browser – es wird niemals ein Bild auf einen Server hochgeladen und es werden niemals Kameraaufnahmen übertragen oder gespeichert. Sie können entweder ein Foto oder einen Screenshot mit einem QR-Code hochladen oder einen Live-Scan mit der Kamera Ihres Geräts durchführen. Dies ist besonders nützlich, um einen unbekannten QR-Code zu überprüfen, bevor der darin enthaltene Link geöffnet wird, oder um QR-Codes aus gedruckten Materialien, Bildschirmen oder Dokumenten zu lesen. Der entschlüsselte Inhalt wird sofort als einfacher Text angezeigt und kann kopiert oder angeklickt werden, wenn es sich um eine URL handelt.
