So konvertieren Sie Text kostenlos in Sprache

Sie möchten einen Aufsatz Korrektur lesen, unterwegs einen Artikel hören oder Voiceovers erstellen? Ihr Browser kann jeden Text vorlesen, ohne Abo und ohne Upload zu Presend. Mit den Stimmen Ihres Geräts verlässt der Text Ihr Gerät nie.

Warum browserbasierte Text-to-Speech?

Cloud-TTS-Dienste wie Amazon Polly, Google Cloud Text-to-Speech oder ElevenLabs liefern hervorragende Ergebnisse, erfordern jedoch:

  • Hochladen Ihres Textes auf ihre Server
  • API-Schlüssel und Entwicklerkonten
  • Bezahlung pro Zeichen oder pro Minute
  • Akzeptieren von Bedingungen, die möglicherweise eine Schulung Ihrer Daten ermöglichen

Für den privaten Gebrauch, Entwürfe oder sensible Inhalte ist die Sprachausgabe im Browser schnell, kostenlos und mit den Stimmen Ihres Geräts privat: Der Text bleibt auf Ihrem Gerät.

So funktioniert SpeechSynthesis

DerSpeechSynthesis-Schnittstelle der Web Speech APIist in jedem modernen Browser integriert. Es nutzt die Stimmen Ihres Betriebssystems:

  • Windows– Microsoft David, Zira und andere Systemstimmen
  • macOS— Hochwertige Siri-Stimmen (Alex, Samantha usw.)
  • Linux– je nach Distribution espeak, Festival oder Piper
  • Android/iOS– Gerätenative TTS-Engines mit regionalen Akzenten

Mit diesen Systemstimmen wird der Text vollständig auf Ihrem Gerät verarbeitet. Manche Browser bieten zusätzlich Online-Stimmen an (Google-Stimmen in Chrome, Microsoft-Stimmen „Online (Natural)“ in Edge), die den Text an Google oder Microsoft senden. Das Tool von Presend markiert sie in der Stimmenliste als „online“ und warnt Sie, wenn eine davon ausgewählt ist.

Anwendungsfälle

  • Korrekturlesen— Wenn Sie Ihre Texte laut vorlesen hören, werden Ihnen Fehler auffallen, die Ihre Augen übersehen
  • Zugänglichkeit— Hören Sie sich Artikel, E-Mails oder Dokumente an, wenn das Lesen schwierig ist
  • Sprachenlernen— Hören Sie die Aussprache von Fremdtexten
  • Inhaltserstellung— Schnelle Voiceover-Entwürfe für Videos oder Präsentationen
  • Multitasking— Hören Sie zu, während Sie kochen, Sport treiben oder pendeln

Anpassen der Spracheinstellungen

Mit dem Tool von Presend können Sie Folgendes steuern:

  • Stimme— Wählen Sie aus allen auf Ihrem System installierten Stimmen, gruppiert nach Sprache
  • Geschwindigkeit— Von 0,5× (langsam) bis 2,0× (schnell). 1,0× ist das natürliche Gesprächstempo
  • Tonhöhe— Höherer oder tieferer Ton. Nützlich zur Hervorhebung oder passenden Inhaltsstimmung

Schritt-für-Schritt-Anleitung

  1. Öffnen Sie das Tool– Gehe zuText-to-Speech
  2. Fügen Sie Ihren Text ein— Geben oder fügen Sie bis zu ein paar tausend Zeichen ein
  3. Wählen Sie eine Stimme— Wählen Sie eine Sprache und eine bestimmte Stimme
  4. Passen Sie Geschwindigkeit und Tonhöhe an– Feinabstimmung nach Ihren Wünschen
  5. Klicken Sie auf Sprechen— Hören Sie sofort zu
  6. Verwenden Sie Pause/Stop— Steuern Sie die Wiedergabe nach Bedarf

Aufzeichnen der Ausgabe

Aufgrund des Sicherheits-Sandboxings können die meisten Browser synthetisches Audio nicht direkt erfassen. Um die TTS-Ausgabe als Audiodatei zu speichern, verwenden Sie den Bildschirmrekorder Ihres Betriebssystems mit Audioaufnahme:

  • Windows— Xbox Game Bar (Win+G) oder OBS Studio
  • macOS— QuickTime Player (Datei > Neue Audioaufnahme) oder Befehl+Umschalt+5
  • Linux— OBS Studio oder parec mit ffmpeg
