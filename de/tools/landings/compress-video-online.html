So komprimieren Sie ein Video ohne Qualitätsverlust

Videodateien sind riesig. Ein 2-minütiger 4K-Clip kann leicht 500 MB überschreiten. So können Sie sie für E-Mail, soziale Medien oder Speicherung verkleinern – ohne sie in einen Cloud-Dienst hochzuladen.

Warum Videokomprimierung wichtig ist

Moderne Telefone zeichnen mit Auflösungen und Bitraten auf, die die meisten Sharing-Plattformen nicht benötigen:

  • E-Mail-Anhänge— Die meisten Anbieter beschränken sich auf 25 MB
  • WhatsApp– Komprimiert Ihr Video stark, was oft die Qualität beeinträchtigt
  • Soziale Medien– Instagram, Twitter und TikTok kodieren sowieso alles neu
  • Cloud-Speicher– Google Drive und iCloud sind schnell mit unkomprimierten Videos voll
  • Website-Hosting– Große Videos verlangsamen die Seitenladezeiten und beeinträchtigen die Suchmaschinenoptimierung

Das Problem mit Online-Kompressoren

Die meisten „kostenlosen Videokompressor“-Websites funktionieren so:

  1. Sie laden Ihr Video auf ihren Server hoch
  2. Sie verarbeiten es (häufig mit einem Wasserzeichen versehen oder auf kostenlosen Ebenen mit einer Qualitätsbeschränkung versehen).
  3. Sie laden das Ergebnis herunter

Das bedeutet, dass Ihre persönlichen Videos, proprietären Aufnahmen oder sensiblen Inhalte auf dem Server eines Fremden liegen. Einige Dienstleistungen:

  • Fügen Sie Wasserzeichen zu kostenlosen Ausgaben hinzu
  • Begrenzen Sie die Dateigröße oder -dauer
  • E-Mail-Registrierung erforderlich
  • Bewahren Sie Kopien Ihrer Uploads auf
  • Verkaufen Sie „Premium“-Funktionen, die einfach sein sollten

So funktioniert FFmpeg.wasm

FFmpeg.wasmist eine WebAssembly-Portierung von FFmpeg, dem branchenüblichen Videoverarbeitungstool, das von YouTube, Netflix und praktisch jeder Videoplattform verwendet wird. Es läuft vollständig in Ihrem Browser:

  • Die ~25 MB WASM-Binärdatei wird einmal heruntergeladen und zwischengespeichert
  • Ihr Video wird in den Browserspeicher geladen
  • FFmpeg verarbeitet es mit denselben Algorithmen wie die Desktop-Version
  • Das Ergebnis wird als Download angeboten – niemals an einen Server gesendet

CRF (Qualitätskontrolle) verstehen

Presend verwendet H.264-Kodierung mit einer Constant Rate Factor (CRF)-Einstellung:

CRF-WertQualitätAm besten für
18–20Optisch verlustfreiArchivierung, professionelle Bearbeitung
21–23Hohe QualitätAllgemeine Verwendung, YouTube-Uploads
24–28Gute Qualität, kleinerSoziale Medien, E-Mail, Web
29–35Akzeptabel, sehr kleinVorschau, Entwurf, mobile Freigabe

Niedrigerer CRF = höhere Qualität, größere Datei. Höherer CRF = kleinere Datei, mehr Komprimierungsartefakte. Der Standardwert 28 ist für die meisten Anwendungsfälle ein gutes Gleichgewicht.

Schritt-für-Schritt-Anleitung

  1. Öffnen Sie das Tool– Gehe zuVideokompressor
  2. Laden Sie Ihr Video hoch— Ziehen Sie eine MP4- oder MOV-Datei per Drag-and-Drop oder wählen Sie sie aus (bis zu ~500 MB)
  3. CRF anpassen— Verwenden Sie den Schieberegler, um Qualität und Dateigröße auszugleichen
  4. Klicken Sie auf Komprimieren— Warten Sie, bis FFmpeg.wasm verarbeitet wird (das erste Laden dauert etwa 10 Sekunden).
  5. Herunterladen— Speichern Sie die komprimierte Datei mit der angezeigten Größenverkleinerung

Tipps für beste Ergebnisse

  • Beginnen Sie mit CRF 28 und passen Sie es je nach Ergebnis an
  • Für soziale Medien bietet CRF 26–28 normalerweise eine hervorragende Qualität bei halber Originalgröße
  • Für E-Mails sollten Sie eine Gesamtgröße von weniger als 25 MB anstreben
  • Das Tool behält die ursprüngliche Auflösung bei – nur die Bitrate wird reduziert
  • Audio wird auf 128 Kbit/s AAC komprimiert, was für die meisten Inhalte transparent ist
