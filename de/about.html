●Presend Alle Werkzeuge API

Über Gegenwart

Presend ist eine kleine, schnelle Sammlung browserbasierter Werkzeuge zum Bereinigen, Komprimieren und Vorbereiten von Dateien, bevor Sie sie teilen. Die Datei-Tools laufen lokal in Ihrem Browser und laden Ihre Dateien nie hoch. Einige andere Tools nutzen unsere API oder einen Online-Dienst; sie sind in der Datenschutzerklärung aufgeführt.

Open Source

Der Code ist auf GitHub verfügbar. Sie können ihn gerne prüfen, forken oder dazu beitragen.
